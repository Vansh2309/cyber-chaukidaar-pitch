# Cyber Chaukidaar — hackCBS 9.0 pitch

Animated web pitch deck for **Cyber Chaukidaar** by team **Order of Phoenix**
(Ishpreet Singh, Prabhmehar Singh Sahni, Vansh Chawla, Avirath Magoo).

Static site: `index.html` + `img/`. No build step.

- Present: open the site, use ← → (or swipe). On the *signals* slide keys 1–4 switch scenarios; on the *decision* slide keys 1–2.
- Each slide has a link: `/#signals`, `/#sitemap`, `/#business`, …
- Deploy on Vercel: import this repository, framework "Other", no build command, output directory `.`.
